## 🎙️ Voice Chat

Le mod **Voice Chat** est **facultatif**. Il permet de parler et d'entendre les autres joueurs. 

<Danger>
  Les soundboard sont autorisés uniquement dans les groupes, et non en général.  Les règles établies de base doivent également être respectées.
  </Danger>

Ensuite appuie sur la touche **V** (touche par défaut) pour **ouvrir le menu du voice chat**. Tu pourras **activer ou désactiver** le micro, **activer ou désactiver** le haut-parleur, régler le **volume** de **chaque joueur**, régler et paramétrer ton **son**.

    <img
      src="/images/other_fonctionnality/voicemod/menu_voicemod.png"
      alt="Menu voice mod"
      className="mx-auto"
    />
<Badge stroke color="blue">𝟏</Badge> **Bouton "Settings"** : paramètrer le son, le micro et le haut-parleur.\
<Badge stroke color="blue">𝟐</Badge> **Bouton "Group"** : Pouvoir créer un groupe avec des personnes.\
<Badge stroke color="blue">𝟑</Badge> **Bouton "Micro"** : Activer/désactiver son micro.\
<Badge stroke color="blue">𝟒</Badge> **Bouton "Son"** : Activer/désactiver son son.\
<Badge stroke color="blue">𝟓</Badge> **Bouton "Adjust Volumes"** : Régler le volume de chaque joueur.\
<Badge stroke color="blue">𝟔</Badge> **Bouton "Record"** : Cacher / Montrer les icones.

### 👨‍👩‍👧‍👦 Les Groupes

Tu peux créer un **groupe** avec des joueurs. Pour cela appuie sur V puis sur le bouton **Group**. 

    <img
      src="/images/other_fonctionnality/voicemod/menu_groupe.png"
      alt="Menu groupe"
      className="mx-auto"
    />

Tu pourras y définir le **nom du groupe** ainsi qu'un **mot de passe** (facultatif).\
Il y a différents types de groupes : 
- **Normal** : Les joueurs non présents dans le groupe ne peuvent pas entendre les joueurs du groupe mais ceux présents peuvent les entendre.
- **Ouvert** : Tous les joueurs (présents ou absents du groupe) peuvent s'entendre mutuellement.
- **Isolé** : Tous les joueurs présents dans le groupe ne peuvent ni entendre ni communiquer avec les joueurs absents du groupe. Les joueurs absents du groupe ne peuvent pas entendre les joueurs présents dans le groupe.
