⚙️ Les **paramètres** permettent de modifier **les variables du chat** et les **notifications** présentes dans celui-ci. 

**➜** Pour **accéder à ces paramètres**, utilise la commande `/parametres` ou `/settings` en jeu.

<img src="/images/other_fonctionnality/settings_menu1.png" 
alt="Première page du menu de la commande /parametres"/>

<img 
src="/images/other_fonctionnality/settings_menu2.png" 
alt="Seconde page du menu de la commande /parametres"/>

**➜** *Clique* simplement sur les boutons pour 🟩**Activer**🟩 ou 🟥**Désactiver**🟥 un paramètre.

<Note>
  La 2ème page du menu **Paramètres** n'est **accessible qu'au spawn**. Pense donc à t'y rendre pour gérer les notifications de vote et l'affichage du grade.
</Note>

**📋 En détail, voici les paramètres disponibles :**
<Steps>
<Step title="🌐 Chat Global">
Le **chat global** permet d'**afficher les messages de base** du serveur. C'est le **canal de discussion principal**, où les autres joueurs discutent.

*Exemple :*
<img src="/images/other_fonctionnality/settings_general.png" 
alt="Exemple d'un message dans le chat général"/>

<Warning>
A moins de vouloir s'isoler totalement du chat, il est déconseillé de désactiver le chat général.
</Warning>
</Step>
<Step title="🙋‍♂️ Recrutement">
Le canal **recrutement** permet de faire une **publicité** pour la recherche ou le **recrutement dans une ville**. 

<img src="/images/other_fonctionnality/settings_recrutement.png" 
alt="Exemple d'un message dans le chat Recrutement"/>

En suivant ce canal, il sera possible de **voir les messages** des autres joueurs, mais également de **publier** dedans avec la commande `/cr [Annonce]`.  
*Un délai de **15 minutes** est imposé entre chaque message dans ce canal.*
</Step>
<Step title="💰 Commerce">
Le canal **Commerce** permet de faire une **annonce** pour tout message relié à l'économie du serveur. 

<img src="/images/other_fonctionnality/settings_commerce.png" 
alt="Exemple d'un message dans le chat Commerce"/>

Que ce soit pour la **promotion dans le chat** d'un warp, d'une boutique, d'une vente, d'un achat ou d'un échange, cela passera par le **chat commerce et la commande : `/cc [Message]`**.  
*Comme pour le canal recrutement, suis le canal Commerce pour voir et publier dans le chat avec un délai de 15 minutes.*
</Step>
<Step title="🏠 Chat de ville">
Le **chat de ville** permet aux membres d'une ville de pouvoir **discuter entre eux**. Seuls des **membres de la ville pourront écrire et voir les messages**.

<img src="/images/other_fonctionnality/settings_ville.png" 
alt="Exemple d'un message dans le chat d'une ville"/>

Utilise **la commande `/v chat [message]`** pour communiquer dans ta ville.

<Note>
    Pour choisir dans le chat de quelle ville tu veux écrire, pense bien à la sélectionner avec `/v select`
</Note>
</Step>
<Step title="🔉 Messages privés">
Les **messages privés**, comme leur nom l'indique, permet d'**échanger des messages seulement entre deux personnes**. Cela peut être pratique pour parler discrètement, ou simplement pour ne pas déranger le chat général.

<img src="/images/other_fonctionnality/settings_prive.png" 
alt="Exemple d'un message privé"/>

- Pour **envoyer un message privé**, utilise la commande `/msg [pseudo] [message]`.  
- Pour **répondre à un message privé**, tu peux soit *cliquer* sur le message, soit utiliser la commande `/r [message]`.

<Warning>
    Attention avec la commande /r, car elle répondra automatiquement à la dernière personne qui t'a envoyé un message privé. Si tu communiques avec plusieurs personnes en même temps, privilégie le /msg.
</Warning>

En désactivant les messages privés dans les paramètres, tu pourras envoyer des messages, mais **pas en recevoir**.

<img src="/images/other_fonctionnality/settings_mp.png" 
alt="Exemple d'un message privé bloqué"/>
</Step>
<Step title="🛜 Demandes de téléportation">
A partir des paramètres, tu peux également **bloquer les demandes de téléportation**.

<img src="/images/other_fonctionnality/settings_teleportation.png" 
alt="Exemple d'une demande de téléportation"/>

- Pour **demander à te téléporter vers quelqu'un**, utilise la commande `/tpa [pseudo]`
- Pour **proposer à quelqu'un de se téléporter vers toi**, utilise la commande `/tpahere [pseudo]`
</Step>
<Step title="🗳️ Notifications de vote">
Toutes les 1h30, tu peux [voter](https://wiki.astralrealms.fr/other_fonctionnality/vote) pour soutenir le serveur. En activant le paramètre de **notifications de vote**, tu recevras dans le chat un message pour te **rappeler de voter**.

<img src="/images/other_fonctionnality/settings_vote.png" 
alt="Exemple d'une notification de vote dans le chat"/>

<Note>
    Les messages apparaissent 1h30 après ton dernier vote, dès que les votes sont **à nouveau disponible**.
</Note>
</Step>
<Step title="🏷️ Affichage du grade">
Enfin, tu as la possibilité de **choisir l'affichage** du [Grade](https://wiki.astralrealms.fr/store/grades) ou du [Rangs](https://wiki.astralrealms.fr/ranks/ranks) devant ton pseudo.  

<Note>
    Par défaut, le grade est affiché mais tu peux désactiver l'option pour que ce soit ton rangs qui apparaisse dans le chat.
</Note>

Choisi l'option qui te plait le plus, et affiche la avec ton [tag](https://wiki.astralrealms.fr/other_fonctionnality/tags) pour **fixer ton identité dans le chat** !
</Step>
</Steps>
---

⚙️ **Les paramètres** te permettent de **personnaliser ton chat et les notifications** que tu souhaites avoir dedans. Tu trouveras également dans le menu **les émojis** (`/emoji`) existants que **tu peux utiliser sur le serveur**, dont le fameux **ICF** !

⛔ Avant de désactiver une fonction, **sois certains que tu n'en auras pas l'utilité**.  
En cas d'abus d'un joueur dans le chat, pense à la commande `/ignore [pseudo]` qui te permet de **ne plus voir et recevoir de messages** de la personne que tu bloques.
