## 📋 Menu 

-``/menu`` : ouvrir le menu principal\
-``/boutique`` : ouvrir le menu de la boutique\
-``/parametres`` : ouvrir le menu des paramètres


## 🌍 Mondes

-``/dimension`` : ouvre le menu des dimensions\
-``/spawn`` : téléporter au spawn\
-``/build`` : téléporter dans la dimension construction\
-``/ressource`` : téléporter dans la dimension ressource\
-``/nether ``: téléporter dans la dimension nether\
-``/end`` : téléporter dans la dimension ender\
-``/rtp`` : téléporter aléatoirement\
-``/tpa `` : envoyer une demande de téléportation pour se téléporter à quelqu'un\
-``/tpahere`` : envoyer une demande de téléportation pour téléporter à quelqu'un sur soi\
-``/tpyes``: accepter la demande de téléportation\
-``/tpno`` : refuser la demande de téléportation\
-``/sethome`` 'nom' : créer un home\
-``/home`` 'nom' : téléporter à un home\
-``/delhome`` 'nom' : supprimer le home

## 🏠 Ville 


-``/v create`` : créer une ville\
-``/v disband`` : supprimer la ville\
-``/v info [nom]`` : afficher les informations d'une ville\
-``/v rename [nom]`` : renommer la ville\
-``/v player [pseudo]`` : afficher les informations d'un joueur\
-``/v invite [pseudo]`` : inviter un joueur à sa ville\
-``/v cancel [pseudo]`` : annuler l'invitation d'un joueur\
-``/v accept`` : accepter l'invitation\
-``/v decline``: refuser l'invitation\
-``/v spawn`` ou ``/vs`` : se téléporter au point de spawn\
-``/v select`` : sélectionner une ville\
-``/v kick [pseudo]``: expulser un joueur de la ville\
-``/v ban [pseudo]`` : bannir un joueur de la ville\
-``/v unban [pseudo]`` : débannir un joueur de la ville\
-``/v leave`` : quitter la ville\
-``/v transfer [pseudo]`` : transférer la priorité\
-``/v members`` : ouvrir le menu des membres\
-``/v online`` : montrer les membres en ligne\
-``/v chat`` : activer/désactiver le chat de ville\
-``/v claim`` : claim le chunk\
-``/v autoclaim`` : claim automatiquement les chunks où l'on se situe\
-``/v unclaim`` : unclaim le chunk\
-``/v settings`` : ouvrir le menu des paramètres\
-``/v view`` : visualiser les claims et sous zone\
-``/v roles`` : ouvrir le menu des rôles\
-``/v broadcast`` : faire une annonce dans la ville\
-``/v motd`` : modifier le message d'arrivée dans la ville\
-``/v logs``: ouvrir le menu des logs de ville.\
-``/v setwarp [nom]`` ou ``/vw set [nom]`` : créer un warp de ville et définir le point de téléportation\
-``/v delwarp [nom]`` ou ``/vw del [nom]`` : supprimer le warp de ville\
-``/v bank`` : ouvrir la banque de la ville sélectionnée\
-``/v balance``: avoir le solde de sa ville\
-``/v deposit`` : déposer de l'argent\
-``/v withdraw`` : retirer de l'argent\
-``/v zone`` : ouvrir le menu des sous zones\
-``/v zone create`` : crée une sous zone\
-``/v zone invite [nom de la sous zone] [pseudo]`` : inviter un joueur dans la sous zone\
-``/v zone kick  [nom de la sous zone] [pseudo]`` : expulser un joueur de la sous zone\
-``/v zone delete [nom de la sous zone]`` : supprimer la sous zone



*Pour plus d'informations concernant les [villes](https://wiki.astralrealms.fr/town/introduction), consulte la page dédiée.*


## 🗼Tour dimensionnelle

-``/tour`` : ouvrir le menu de la tour\
-``/party create`` : Créer un groupe\
-``/party invite`` [pseudo] : inviter un joueur dans son groupe\
-``/party accept`` : accepter l'invitation\
-``/party decline`` : refuser l'invitation\
-``/party leave`` : quitter le groupe\
-``/party kick`` : expulser un joueur de son groupe\
-``/party transfer :`` transférer la propriété du groupe\
-``/party disband :`` dissoudre le groupe

*Pour plus d'informations concernant la [tour dimensionnelle](https://wiki.astralrealms.fr/tower/introduction), consulte la page dédiée.*


## 💵 Economie

-``/money`` : voir son solde\
-``/baltop`` : voir le classement top 10\
-``/pay`` [pseudo] [montant] : payer un joueur\
-``/ah`` : ouvrir le menu de l'ah\
-``/ah sell`` [prix] : vendre l'item de sa main


## 💪 Progression 

-``/rang`` : ouvrir le menu des rangs\
-``/missions`` *[eco/farmer/fisherman/hunter/jobs-level/lumberjack/miner/other/player-level]* : ouvrir le menu des missions pour une catégorie spécifique\
-``/metier`` ou ``/jobs`` : ouvrir le menu des métiers\
-``/jobs claim`` : récupérer les récompenses disponibles des niveaux de métier\`
-``/parchemins`` : ouvrir le menu des parchemins, permettant de voir les récompenses pour chaque rareté\
-``/rewards`` : ouvrir le menu des récompenses journalières et des temps de jeu\
-``/votes`` :  ouvrir le menu des votes

## 🎤 Social

-``/msg [pseudo]`` : envoyer un message à un joueur\
-``/ignore [pseudo]`` : ignorer un joueur\
-``/unignore [pseudo]`` : désignorer un joueur\
-``/togglepm`` : activer/désactiver les mp\
-``/chatcommerce``ou ``/cc``  : envoyer un message dans le chat commerce (⏳ 15 minutes)\
-``/chatrecrutement``ou ``/cr``  : envoyer un message dans le chat recrutement (⏳ 15 minutes)\
-``/unscribe`` [recrutement/commerce/global] : désactiver le chat recrutement/commerce/global\
-``/tags``: ouvrir le menu des tags
