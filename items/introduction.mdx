## Où trouver les items customs

Les items customs sont accessibles via plusieurs sources :

- [Récompenses de métiers](https://wiki.astralrealms.fr/jobs/rewards)
- [Les enchères](https://wiki.astralrealms.fr/events/encheres)
- Caisse [Vote](https://wiki.astralrealms.fr/other_fonctionnality/vote#-caisse-de-vote)

## 🔧 Items utilitaires

### Mithril
Le **mithril** permet de rendre **incassable** l’item custom de ton choix.

- L’item ne perdra **plus aucune durabilité**
- Pour l’utiliser, il suffit de **déplacer le mithril** sur l’item concerné

### Orbe de réparation
L’**orbe de réparation** permet de **restaurer la durabilité** d'un item custom de ton choix.

- L’item retrouve sa **durabilité maximale**
- Pour l’utiliser, il suffit de **déplacer l’orbe de réparation** sur l’item concerné
