## Étape 1 : Installer Mint

Mint est l'outil de développement que nous utilisons pour construire et prévisualiser le wiki. Il est très facile à installer.
1. Ouvrez un terminal (sur Mac : Terminal, sur Windows : PowerShell ou Command Prompt)
2. Tapez la commande suivante et appuyez sur Entrée :
```bashnpm npm i -g mint
   ```  
3. Si vous êtes sur Windows, vous devrez peut-être ajuster la politique d'exécution pour permettre l'installation de Mint.

Ouvrir PowerShell et tapez la commande suivante et appuyez sur Entrée :
```bashnpm Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser   
```  

## Étape 2 : Installer les Extensions Mintlify pour VSCode

VSCode est un éditeur de code gratuit et très puissant.

1. Allez sur <a href="https://code.visualstudio.com/" target="_blank">code.visualstudio.com</a>
2. Cliquez sur le bouton de téléchargement pour votre système
3. Lancez l'installateur et suivez les étapes (options par défaut recommandées)

<Callout type="tip">
    <strong>Astuce :</strong> Cochez la case "Add 'Open with Code' to action" (ou équivalent) lors de l'installation
    pour pouvoir ouvrir des dossiers directement depuis VSCode.
</Callout>

4. Une fois VSCode installé, ouvrez-le et allez dans l'onglet des extensions (icône de carré avec quatre carrés à l'intérieur)
5. Recherchez "Mintlify" et installez les extensions suivantes :

  <img src="/images/welcome/extensions_mintlify.png" alt="Mintlify extensions" className="mx-auto"/>

## Étape 4 : Clone le dépôt GitHub sur Gitkraken

1. Cliquez sur « GitHub.com ».
2. Authentifiez-vous avec votre compte GitHub.
3. Sélectionnez le dossier de destination du dépôt.
4. Choisissez le dépôt docs de l'organisation Astral-RealmsMC.
5. Cliquez sur « Clone the repo! » afin de cloner le dépôt sur votre ordinateur.



  <img src="/images/welcome/Gitkraken_clone.png" alt="Gitkraken" className="mx-auto"/>

## Étape 5 : Faire vos modifications

Maintenant vous pouvez modifier les fichiers !

<AccordionGroup>
    <Accordion title="Créer un nouveau fichier" icon="file-plus">
        <ol>
            <li>Dans l'explorateur de fichiers (gauche), faites un clic droit</li>
            <li>Sélectionnez <strong>"New File"</strong></li>
            <li>Donnez un nom au fichier avec l'extension <code>.mdx</code></li>
            <li>Exemple : <code>ma-nouvelle-page.mdx</code></li>
        </ol>
    </Accordion>

    <Accordion title="Modifier un fichier existant" icon="edit">
        <ol>
            <li>Cliquez sur le fichier que vous voulez modifier</li>
            <li>Faites vos changements dans l'éditeur</li>
            <li>Sauvegardez avec <code>Cmd+S</code> (Mac) ou <code>Ctrl+S</code> (Windows/Linux)</li>
        </ol>
    </Accordion>
</AccordionGroup>

<Callout type="info">
    <strong>Format des fichiers :</strong> Nous utilisons le format <strong>MDX</strong> (Markdown avec des composants).
    C'est comme du Markdown normal mais avec des composants Mintlify supplémentaires.
</Callout>

## Étape 6 : Prévisualiser vos changements

Avant de proposer vos changements, vous pouvez les voir en direct.

1. Ouvrez un terminal dans VSCode (<code>Ctrl+`</code> ou <strong>Terminal</strong> → <strong>New Terminal</strong>)
2. Lancez le serveur de prévisualisation :
```bash
mint dev
   ```
4. Ouvrez votre navigateur sur <code>http://localhost:3000</code>

<Note>
    Vos changements apparaissent en temps réel à mesure que vous modifiez les fichiers !
</Note>



## Étape 7 : Publier ses modifaications sur le Wiki

  <img src="/images/welcome/gitkraken_push.png" alt="Gitkraken" className="mx-auto"/>

1. Cliquez sur le WIP
2. Cliquez sur Stage All Changes
3. Mettez un titre à votre push (exemple : Ajout de la page[...], corrections des fautes d'orthographe,...)
4. Cliquez sur Stage Changes to Commit
5. Cliquez sur Push (ça le mettra directement sur le wiki en ligne)
6. Rectangle rouge : fichiers modifiés (possibilité de voir les modifications en cliquant sur chaque fichier)
7. Rectangle bleu : historique des dernières modifications (possibilité de voir les changements en cliquant sur chaque commit)


 <Tip>
 Avant de faire des modifications, assurez-vous de faire un pull pour récupérer les dernières modifications du wiki. Cela évitera les conflits de fusion. Ouvrez gitkraken, cliquez sur le dépôt "docs", puis cliquez sur "Pull" pour synchroniser votre copie locale avec le dépôt distant.
 </Tip>

## Problèmes fréquents

<AccordionGroup>
    <Accordion title="Git n'est pas reconnu" icon="alert-circle">
        <p>Assurez-vous que Git est bien installé et que vous avez redémarré votre terminal après l'installation.</p>
    </Accordion>

    <Accordion title="Permission refusée" icon="lock">
        <p>Vérifiez que vous avez bien forké le dépôt et que vous êtes connecté à votre compte GitHub.</p>
    </Accordion>

    <Accordion title="Conflits de fusion" icon="git-merge">
        <p>Si le dépôt original a changé, vous devrez peut-être mettre à jour votre fork. Demandez de l'aide sur Discord
            si cela arrive !</p>
    </Accordion>

    <Accordion title="La prévisualisation ne fonctionne pas" icon="alert-triangle">
        <p>Assurez-vous d'être dans le bon dossier et que le port 3000 n'est pas déjà utilisé par une autre
            application.</p>
    </Accordion>
</AccordionGroup>
