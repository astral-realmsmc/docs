Le **voteparty** se déclenche tous les **750 votes**. Lorsqu'il est délenché, un message t'invitant à **rejoindre le spawn** sera envoyé dans le chat.\
Le principe ? **Taper le lama tel une piñata**. Donner **un coup** te donnera **une récompense aléatoire**. Le lama a **250 de vie**, ce qui signifie qu'il y a **250 récompenses**.

Tu pourras voir la **progression** des 750 votes sur l'HUD.

alt="HUD voteparty"
