### ⏲️ Déroulement

Les enchères ont lieu **tous les soirs à 21h** (heure française). Pour y participer, utilise la commande `/auction`. Si aucune enchère n’est en cours, l’heure de la prochaine session te sera indiquée.

Le **fonctionnement** est simple : un **objet aléatoire** est proposé aux enchères et les **joueurs peuvent ensuite enchérir** dessus.\
Pour **placer une enchère**, il suffit de faire un **clic droit** afin d’ouvrir le menu dédié. Si **aucune autre enchère** n’est effectuée dans les **5 secondes** suivant la tienne, tu **remportes** alors le lot.
